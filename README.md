# La-fortuna-del-Decameron
This repository contains the material for a Website demo; a DH project about the influence of the Decameron on the arts over the centuries.

The project consists in a web site that allows the user to navigate throu several items (works of art, books, movies), inspired by Boccaccio's novels. If you are interested in knowing more about the influence of the Decameron on arts and culture over the decades, click on the project and have a look!

You can find activeted the link to the complete catalogue and to the page of the item "Stories of Nastagio degli Onesti - by Botticelli".
## Material for the Website
1. homepage (file index.html)
2. pagina completa del **catalogo** (list-items.html)
3. pagina di un **singolo item** (item.html)
4. **foglio di stile** impiegato per l'intero sito (style/style.css)
5. fogli di stile specifici per le varie pagine, da sovrascrivere al file css principale
6. **immagini** richiamate nel sito (cartella img)
7. script **js** utilizzato (js/main.js)
8. pagina con tabella dei dati e riconciliazione di autorità (data.html)
9. file CSV/JSON scaricabili dalla pagina dati
10. pagina contenente una mappa dei luoghi, creata con Leaflet JS (map.html)
